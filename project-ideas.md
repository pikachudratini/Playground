# Claude Code Project Ideas

A hand-picked collection of beginner-friendly things real people have built (or
suggested) with Claude Code. Pick one that sounds fun and tell Claude you want
to build it — that's the whole point.

> Last refreshed: May 2026

---

## Quick wins (under an hour)

### 1. A one-page personal website
Just a single web page with your name, what you're into, and how to reach you.
Works in any browser. No server, no setup.
- **Starter prompt**: *"Make me a single-file personal website with my name,
  a short bio, and links to my email and one social profile. Use clean modern
  styling."*

### 2. Expense tracker
Type in what you spent and on what. It groups by category and shows totals.
- **Starter prompt**: *"Build me a simple expense tracker. I'll type in
  amount + category. Show me totals by category and total spent this month."*

### 3. Daily inspiration generator
A page or script that gives you one random quote / prompt / idea per day.
- **Starter prompt**: *"Make me a script that prints one motivational quote
  per day, picked randomly from a list of 50 you suggest."*

### 4. Rename messy files for me
Point Claude at a folder of PDFs / screenshots / downloads. It reads each one
and renames it based on what's actually inside. Real people have done this to
clean up years of chaos.
- **Starter prompt**: *"Look at the PDFs in my Downloads folder. For each one,
  read the first page and rename the file based on the topic in 2–3 words."*

### 5. Temperature converter
Tiny tool that converts Celsius / Fahrenheit / Kelvin. Sounds boring but
teaches you the loop: ask, generate, run, fix.
- **Starter prompt**: *"Make a temperature converter I can run in chat. I'll
  type a number and a unit, it converts to the other two."*

## Weekend projects (a few hours, more rewarding)

### 6. A retro space shooter game
A simple 2D game in the browser. You can ask Claude to add enemies, change
difficulty, swap art. Great because you *see* changes instantly.
- **Starter prompt**: *"Build me a retro 2D space shooter game I can play in
  my browser. One file, arrow keys to move, spacebar to shoot."*

### 7. Personal organization assistant
A script that scans a folder, finds duplicate files, suggests a tidier
structure, or moves things into folders by type.
- **Starter prompt**: *"Help me organize my Downloads folder. Group files by
  type, flag duplicates, and suggest a cleanup plan before doing anything."*

### 8. A "second brain" notes index
A folder of markdown notes Claude can search and summarize for you. Like a
personal Wikipedia of things you don't want to forget.
- **Starter prompt**: *"Set up a notes folder. When I tell you a fact or idea,
  save it as a markdown file with tags. Let me search and summarize later."*

## How to use this file

1. Read through, find one that doesn't scare you.
2. Copy the starter prompt.
3. Paste it into chat with Claude (here, on the mobile app).
4. Build it together. Get stuck? Just say so.

You don't have to pick the "right" one. Picking *any* one and finishing it
beats studying the list forever.
